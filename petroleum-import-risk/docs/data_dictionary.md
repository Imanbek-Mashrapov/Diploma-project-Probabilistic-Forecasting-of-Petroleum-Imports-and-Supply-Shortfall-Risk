# Data dictionary

Files are in `data/research/`. Generated by `python run.py phase2`.

## petroleum_imports_monthly.parquet

42,140 rows.

| Column | Type | Meaning |
|---|---|---|
| `iso3` | str | Reporter ISO3 code |
| `product_group` | str | Product group key |
| `period` | int64 | Month as YYYYMM |
| `import_mass_t` | float64 | TARGET. Clean import mass in metric tonnes; missing unless data_status is observed |
| `import_mass_t_original` | float64 | Mass before the unit-value check |
| `mass_t_incl_volume_estimate` | float64 | Original mass plus labelled litre-based estimate; annual comparison only, never a target |
| `import_value_usd` | float64 | Import value in USD as reported, CIF for most reporters |
| `unit_value_usd_t` | float64 | Value divided by original mass |
| `uv_relative` | float64 | Brent-deflated unit value over its centred 13-month median; cleaning only, uses future months |
| `total_source` | str | partner_sum, or world_row where partner rows are absent |
| `n_partners` | float64 | Partner rows in the sum, including those without mass |
| `partner_to_world_mass` | float64 | Partner-sum mass over World-row mass |
| `partner_to_world_value` | float64 | Partner-sum value over World-row value |
| `share_estimated` | float64 | Share of mass flagged as estimated |
| `share_mass_recovered_from_qty` | float64 | Share of mass taken from kg quantity fields |
| `flag_uv_low` | object | Unit value too low; mass removed |
| `flag_uv_high` | object | Unit value too high; mass kept, value suspect |
| `flag_mass_outlier` | object | Robust |z| above 4 on log mass; kept |
| `classification` | str | HS edition of the first row in the sum |
| `export_mass_t` | float64 | Clean export mass, tonnes, for trade orientation |
| `first_released` | datetime64[ns] | First Comtrade release of the reporter-month |
| `data_status` | str | observed, mass_rejected_by_check, value_reported_mass_missing, no_record_in_published_month, reporting_interruption, outside_reporting_span |
| `month` | datetime64[us] | First day of the month |
| `publication_lag_days` | float64 | Days from month end to first release |
| `active_suppliers` | float64 | Partners with positive mass, excluding self and non-suppliers |
| `largest_supplier_share` | float64 | Largest supplier's mass share |
| `top3_supplier_share` | float64 | Three largest suppliers' mass share |
| `hhi` | float64 | Monthly sum of squared mass shares |
| `hhi_12m` | float64 | HHI of mass pooled over 12 months; null with fewer than 6 observed |
| `largest_supplier_iso` | str | Largest supplier's code |
| `russia_share` | float64 | Russia's mass share |
| `nes_share` | float64 | Share of unallocated partners |
| `country` | str | Reporter name |
| `product_label` | str | Product group with its HS codes |
| `classification_flag` | str | fuel_lines_suspect, 271019_misses_blended_diesel or empty |
